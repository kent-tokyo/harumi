# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| 1.x     | Yes       |
| < 1.0   | No        |

## Reporting a Vulnerability

**Please do not open a public GitHub issue for security vulnerabilities.**

Use GitHub's private vulnerability reporting instead:  
→ **[Report a vulnerability](https://github.com/kent-tokyo/harumi/security/advisories/new)**

### What to include

- Description of the vulnerability and potential impact
- Steps to reproduce or a minimal proof-of-concept
- Affected versions (if known)
- Any suggested fix (optional)

### Response timeline

| Milestone | Target |
|-----------|--------|
| Acknowledgement | Within 2 business days |
| Severity assessment | Within 5 business days |
| Fix or mitigation | Within 14 days for critical issues |

We will coordinate disclosure with you and credit reporters in the release notes.
